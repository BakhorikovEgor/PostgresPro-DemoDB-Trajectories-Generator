# Flight Trajectory Generator for Postgres Pro Demo DB

Данный проект является расширением для [демонстрационной базы данных «Авиаперевозки»](https://postgrespro.ru/education/demodb) от Postgres Professional. Он добавляет возможность генерации, хранения и KML-выгрузки реалистичных пространственно-временных (4D) траекторий полетов с использованием возможностей **PostgreSQL** и **PostGIS**.

## О проекте

По умолчанию демо-база содержит данные о расписании рейсов и точечные координаты аэропортов, но не содержит самих маршрутов движения. 
Разработанный SQL-модуль решает эту проблему: он массово генерирует ортодромии (кратчайшие пути по сфере) и накладывает на них физическую модель высоты (набор, крейсерский эшелон, снижение), привязывая каждую точку ко времени.

### Ключевые особенности
* **Математика на стороне СУБД:** сферическая тригонометрия рассчитывается прямо в базе с помощью функций PostGIS (`ST_MakeLine`, `ST_Segmentize`, `ST_Distance`).
* **Учет кривизны Земли:** Построение дуг большого круга вместо плоских прямых.
* **Физика полета:** Учет градиентов набора высоты (3.3%) и снижения (5.2%) по стандартам ICAO.
* **Производительность:** Использование `UNLOGGED` таблиц и `GIST`-индексов для мгновенной массовой вставки и поиска геоданных.
* **3D Визуализация:** Готовый bash-скрипт для экспорта данных в формат `.kml` для нативной отрисовки, например, в Google Earth Pro.

---

## Структура репозитория

* `docker-compose.yml` — конфигурация для быстрого развертывания БД с установленным расширением PostGIS.
* `01_create_tables.sql` — DDL-скрипт создания нежурналируемой таблицы `flight_trajectories` и необходимых индексов.
* `02_generate_procedure.sql` — исходный код хранимой процедуры на языке PL/pgSQL, реализующей алгоритм генерации точек.
* `03_export_kml.sh` — Bash-скрипт для случайной выборки 200 рейсов и их экспорта в файл 3D-формата KML.

## Пошаговая инструкция по генерации

### Шаг 0. Подготовка
Перед началом работы у вас уже должна быть развернута и полностью проинициализирована стандартная демонстрационная база данных «Авиаперевозки» (БД `demo`).
1. Поднимите контейнер с помощью `docker-compose.yml` (он включает необходимое расширение PostGIS).
2. Загрузите базовую схему и сгенерируйте данные расписания стандартными средствами Postgres Pro (скрипт `install.sql` и функция `generate(...)`).

### Шаг 1. Создание структуры для траекторий
Когда ядро базы готово, необходимо создать таблицу для хранения 3D-геометрий и индексы к ней. 
Выполните в БД `demo` скрипт:
* 📄 `create_tables.sql`

### Шаг 2. Загрузка алгоритма генерации
Добавьте в базу хранимую процедуру на языке PL/pgSQL, которая содержит всю математику расчета ортодромий и высотных профилей. 
Выполните в БД `demo` скрипт:
* 📄 `create_generator_procedure.sql`

### Шаг 3. Запуск расчетов
Запустите сам процесс генерации координат для всех перелетов в базе. Для этого выполните простую SQL-команду:
```sql
CALL bookings.generate_all_trajectories();
```

### Шаг 4. Выгрузка отчёта (опционально)
Вы можете выгрузить данные о траеториях в нужный вам формат (см. в репозитории папку `export_scripts`).
